# I_AM_NOT_AFK
I_AM_NOT_AFK is a very simple *.exe that presses WASD randomly.
This way, you don't have to worry about getting kicked for inactivity. 

By pressing F7 you start the application, to stop it press F6.

The .exe should live inside your taskbar.

**How2Use**
Simpply download the .zip, extract it and run the .exe .
How to turn on and off the script is explained at the top.

Have fun!
